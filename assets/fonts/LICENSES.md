# Fonts

Subsets made by `scripts/fonts.py` from the fonts of the Kotlin desktop app. All are free fonts:

| Font | License |
|---|---|
| Manrope, JetBrains Mono, Nunito, Comfortaa, Caveat, Cormorant Garamond, Forum, Playfair Display, Russo One, Spectral, VT323, Noto Sans JP, Noto Serif JP | SIL Open Font License 1.1 (Google Fonts) |
| Rubik Wet Paint (whole font, for Full; Mini has only `assets/brand/wordmark.png` drawn with it by `scripts/wordmark.py`) | SIL Open Font License 1.1 (Google Fonts) |
| Tabler Icons (webfont) | MIT |

The OFL allows bundling and subsetting; subsets keep the original names as required by the reserved-name rules
where applicable.

Onest (`Onest-Regular/Medium/SemiBold/Bold.ttf`, Mini's text font): static weights cut from the variable
`Onest[wght].ttf` of Google Fonts by `scripts/onest.py` (Latin, Cyrillic, punctuation). Copyright 2021 The Onest
Project Authors (https://github.com/googlefonts/onest), SIL Open Font License 1.1.
